# ADR-0002: 語彙監査は固定参照資源と形態素根拠を分離する

## Status

Accepted

## Context

既存`terms`は専門用語候補の抽出であり、一般名詞複合語を意図的に対象外とする。一方、一般的な構成語から作られた低頻度の複合語や、同じ概念について漢語・和語など異なるレジスターが混在する箇所には、人が確認すべきものがある。Sudachiの品詞、辞書形、読み、正規形だけでは意味的な同義性を判定できない。

## Decision

既存JSONを変えず、読み取り専用の`lexical-audit`コマンドを追加する。一般名詞系列はSudachiの品詞列から抽出し、新奇性は本文頻度、固定JSON参照資源のコーパス頻度、定義手掛かり、登録語を別々に確認する。表記揺れはSudachi正規形の一致、レジスターの揺れは参照資源へ明示した語集合の共起だけで判定する。全てinfo確認候補とし、既存lintの禁止語完全一致だけは元のwarnを維持する。

## Consequences

- 実行時のネットワーク、埋め込みモデル、確率的判定を必要とせず再現できる。
- 参照資源が知らない同義語は検出不能である。表層文字種だけから漢語・和語を推測しない。
- Suikoは原稿を変更せず、意味を伴う言い換え候補も自動適用しない。

## Alternatives considered

### 重い埋め込みモデルを同梱する

再現性、配布サイズ、誤った同義判定の説明可能性に不利なため採用しない。

### 個別の不自然語を禁止語へ追加する

未知語へ拡張できず、根拠の異なる禁止語と新奇性を混同するため採用しない。
