# 推敲の検査記録

`check`は最終稿に対する検査を一度に実行し、`verify`はその検査対象が提出前に変わっていないかを確認する。どちらも本文を書き換えない。文脈による修正はSkillまたは書き手が行う。

## 入力と保存

```sh
suiko check final.md --before original.md --material measurements.md --genre tech --json
suiko verify final.md.suiko-check.json --json
```

原文がなければ`--before`を省略する。資料は`--material`を繰り返して指定する。原文と資料を別の役割として扱い、資料を原文とみなした差分で全文の脱落を判定しない。記録の出力先は`--record`で変更できる。

対象はUTF-8のMarkdown・テキストファイルで、標準入力は使わない。原文・最終稿・資料の内容を読み込んだ時点でハッシュを取り、検査終了時にも変わっていないか確認する。保存は同じディレクトリの一時ファイルを経由する。既存の正常な検査記録だけを更新し、無関係なファイルや入力と同じパス、シンボリックリンクを出力先にすることは拒否する。

## 記録の構造

保存ファイルは`format: "suiko-check"`、`schema_version: 1`、`record`、`checksum`を持つ。未知の形式は読み込まず、現在のCLIで再検査する。

`record`には次の内容を保存する。

- `suiko_version`、`tool_sha256`、`checked_at_unix_seconds`: 検査に使った実行ファイルと時点。埋め込み辞書やルールの変更も実行ファイルのハッシュに反映される。
- `final_file`、`before`、`materials`: 絶対パスとUTF-8ファイルのSHA-256。原文を指定しなければ`before`は`null`。
- `configuration`: 設定の絶対パスとハッシュ。自動検出先に設定がない場合はハッシュが`null`。`--no-config`ではこの項目自体が`null`。
- `options`: 解決済みの`genre`、`experimental`、`fail_on`。再実行時に呼出先ディレクトリの設定へすり替えない。
- `report`と`threshold_exceeded`: lint、読解負荷、diff、資料照合の結果と、指定した重要度以上の候補があったか。原文・資料を指定しなかった検査は`null`。

`checksum`は記録の誤編集や破損を検出するための値で、署名ではない。意図的に記録を書き換えた第三者に対する証明には使えない。資料や原文そのもののコピーは作らず、検出箇所の抜粋を保存する。再確認が必要な間は、記録と参照先の入力を一緒に保管する。

## JSONと終了コード

`check --json`は`status: "checked"`、記録の保存先`record`、保存した検査の内容`check`を返す。保存できなければ成功結果を返さない。

`verify --json`は`status: "current" | "stale"`、`record`、`replayed`、`threshold_exceeded`、`changes`を返す。`changes`の各要素は`kind`、`path`、`detail`を持つ。現在の状態が一致していても、保存時の重要度条件を超える候補があれば終了コード2となる。

| 終了コード | 動作 |
|---|---|
| 0 | 検査または照合が完了し、指定した重要度条件に到達していない |
| 1 | 入力、設定、保存、記録形式・整合性のエラー |
| 2 | 重要度条件に到達した、または検査後に入力・設定・実行ファイル・再実行結果が変わった |

`verify`の一致は検査対象の一致であり、残った候補の採否や本文の自然さを判定した結果ではない。`--replay`は一致した入力だけで検査を再実行する。不一致の状態を新しい記録として保存する場合は、候補を読み直せる`check`を使う。

## 資料照合の範囲

| category | 読み合わせること |
|---|---|
| `material_value_unmatched` | 本文の値・単位を資料で確認できない。単位換算や数の表記の違いも確認する |
| `material_value_context` | 同じ値はあるが、対象・環境・測定指標・条件が対応していない可能性がある |
| `material_claim_unmatched` | 効果・保証・一般化の表現に対応する記述を確認できない |
| `material_caveat` | 関連資料にある未確認事項・予定・限定条件が本文では確認できない |

形態素の内容語、限定した環境・指標の分類、留保の表現を使う。意味の同一性を推定するモデルは使わない。別の段落からの主語の補完、複雑な係り受け、同義語、単位換算、資料同士の矛盾の解消は対象外。確認候補として原文と資料を読める行を返し、正誤や合格を自動判定しない。
