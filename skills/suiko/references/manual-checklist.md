# CLIを使えない場合の推敲

機械検査を使えなくても、修正依頼では[既定の推敲手順](revision-pass.md)に沿って全文を仕上げる。
検出件数やCLIの実測値として報告しない。診断だけ、誤字だけなどの指定は優先する。

| 観点 | 確認すること |
|---|---|
| 主述・対象・修飾 | 誰の何の動作か、条件がどこに掛かるか。主語や相手を推測で足さない |
| 論理・段落 | 接続・指示語・問いと答えを追えるか。条件や理由の途中で文を分けない |
| 文末 | 依頼・許可・能力・義務・予定・実施済みを区別し、確度と敬体・常体を保つ |
| 語彙・表記 | 比喩・連用形名詞・名詞化・翻訳調・補助動詞を[修正判断](revision-catalog.md)で確認する |
| 原文・資料との対応 | 数値・単位・対象・条件・時点の組を保ち、根拠のない因果・感情・約束を加えない |

読みづらい長文は、修飾先や列挙を受ける述語を追えるように整える。文長・接続詞率・
語彙の多様性・体言止めの数を目標にして直さない。必要な反復、比較、正式語、原文の声は残す。
見出し・箇条書き・表・台詞も、[用途別の扱い](revision-context.md)に沿って読む。

変更前から変更後へ脱落を、変更後から原文・資料へ追加の根拠を照合する。
直せる箇所を仕上げ、必要な確認は本文の外へ分ける。検出ゼロや全指摘の台帳化を完了条件にしない。
同じ箇所を直しては戻す場合は、別の語を当て続けず、文の関係と用途を確認する。

最終稿を通読し、実際に直した点と未実施の検査を簡潔に伝える。本文だけの指定なら本文だけを返す。
