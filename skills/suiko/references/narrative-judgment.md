# エッセイで残す反復・迷い・語り手の判断

エッセイや体験記を直すとき、反復、留保、文体の変化を削る前に読む。読みやすさを整えた結果、語り手の立場や考え直した理由まで消えていないかを確かめる。操作手順や意思決定のための報告書へ、そのまま適用しない。

## 読んだ文章と、そこから考えたこと

2026-09-06に megamouth の次の10本を本文の末尾まで読んだ。2020〜2026年から、随想、仕事の論考、会話を中心にした文章を選んだ。以下は読者としての解釈であり、執筆方法や出来事の実在を判定したものではない。本文は転載せず、推敲に使う観点を整理した。

- [無念の不在](https://www.megamouth.info/entry/2026/08/01/192846): 祖父についての記憶を、現在の自分の姿から読み直している。物や動作の描写が、後から自分にも向く判断につながる。思い出せない動機は、説明で埋めていない。
- [班長を待ちながら](https://www.megamouth.info/entry/2026/05/17/221035): 当初の不満を説明するうちに、自分に都合のよい態度も見えてくる。同じ話題に戻っても、読者が語り手を見る目は変わる。結末でも行動の問題は解消されない。
- [駆け込み面接](https://www.megamouth.info/entry/2026/05/12/215443): 語り手は、自分の仕事を擁護するのに不都合な後日談も語る。丁寧な応答が崩れていく過程には、面接が進むにつれて追い詰められる事情がある。
- [本屋の宗教](https://www.megamouth.info/entry/2026/01/28/172945): 自作の道具の失敗を通じて、理想を掲げる自分の都合を疑う。抽象的な説明や比喩も多いが、最後には買った物の音という小さな感覚へ戻る。
- [残業キャンセル界隈と企業カルチャーの死](https://www.megamouth.info/entry/2025/12/11/235309): 冒頭では若者への非難を大げさになぞり、そこから古い側の価値観を問い直す。後半は明示的な論点整理と提案が中心で、すべてを場面描写だけで進めてはいない。
- [今はもう遠い昔。あの雲のむこうにはFlashがあった](https://www.megamouth.info/entry/2025/08/03/014223): 技術への愛着と、それが必要とされなくなった失望を語る。その後の他者の思い出によって、自分の悲観的な評価にも修正が入る。小さな救いのある結末も成立している。
- [ガラス板の向こうから挨拶を](https://www.megamouth.info/entry/2025/06/26/005614): 母校での待ち時間から過去の学校生活へ移り、社会についての見方を述べ、手続きの終了へ戻る。比喩と冒頭の回収が、語り手の立ち位置を伝えている。
- [灯光](https://www.megamouth.info/entry/2025/05/30/002910): 他者との短いやり取りや動作が、関係の近さを示す。消息については、噂と確認した事実を混ぜない。分からないままにした自分の選択も、肯定しきらずに残す。
- [件数噺（くだんばなし）](https://www.megamouth.info/entry/2025/04/07/070754): 同じ言葉が会話の行き詰まりを作り、最後には話者と指す対象を変えてオチになる。語り手の金銭的な都合も明かされ、一方的に相手を笑うだけでは終わらない。
- [パラノイアのプログラマと第６感](https://www.megamouth.info/entry/2020/09/16/012003): 現場の不合理を批判する前に、自分も問題を放置した過去を置く。具体的な確認作業と組織への考察を往復し、最後の問いに語り手自身の負担がつながる。

複数の記事で「一人の人が考えている」と感じられる理由は、判断が語り手の立場や出来事に結びつき、その判断を保ちにくくする事情も本文に残ることにある、と考えた。細部の多さだけでなく、何を見て評価を変えたのかが読める。

一方、未解決の結末、弱い断定、短文ばかりが共通するわけではない。明確なオチ、提案、長い抽象的な説明、強い比喩もある。語り手の存在感があっても、一般化の根拠や比喩の分かりやすさは別に点検する。1人の10本を、人間の執筆を見分ける条件や、すべての良い文章に必要な型へ広げない。

## 削る前に確かめること

| 表現 | 残す根拠 | 直す候補になる場合 |
|---|---|---|
| 固有の物・動作・数値 | 後の判断や行動の理由になる。省くと、なぜそう考えたか分からなくなる | 本筋と関係がなく、具体的に見せる飾りとして置かれている |
| 自分の説明への異議 | 新しい観察や、自分に不都合な事情によって説明を修正している | 「いや」「そう単純ではない」だけで、何を考え直したか分からない |
| 同じ言葉への回帰 | 間に起きた出来事によって、同じ言葉の意味や重みが変わる | 同じ理由、同じ評価を言い直すだけで読みが進まない |
| 留保・否定 | 記憶と記録、推測と確認、賛成と消極的な容認などの違いを保つ | 留保の対象が分からず、確かな部分まで曖昧にする |
| 長短や語調の変化 | 注意が向く先、相手との関係、感情の変化に対応している | リズムを変えるためだけに文を切る、敬体と常体を混ぜる |
| 比喩・皮肉 | 比喩の対応が本文で分かる。皮肉では、誰の価値観をなぞり、何を批判しているかが読める | 比喩で根拠を代用する。皮肉の対象が曖昧で、文字どおりの主張と区別できない |
| 結末と冒頭の回収 | 出来事を経て評価が変わる、発言の意味が変わる、あるいは未解決だと分かる | 結論に合わせて出来事を足す。本文の問いと関係のない教訓や余韻を付ける |

迷ったら、その表現を削った版と比べる。「何が起きたか」だけでなく、「語り手はどこまで知り、何に困り、どの判断を変えたか」が同じように伝わるかを見る。変わってしまうなら、残す理由を判断台帳に書く。[独自の練習例](examples.md#残す判断の練習例)も参照する。

## 形態素解析と目視の分担

形態素の原形や品詞は、反復する語句、否定、推量の助動詞、文末の型を見つける材料になる。ただし、同じ対象の呼び直しや否定の及ぶ範囲は、語の一致だけでは決まらない。次の情報を読む場所の目印として扱う。

- 反復の候補では、出現箇所と間の段落を並べて読む。間に加わった出来事や評価があるかは、本文から判断する。
- 否定や推量の候補では、何を否定し、何について確信がないのかを確認する。肯定文や断定へ変える前に、態度と確実さが保たれるかを見る。
- 文末の変化では、引用・会話と地の文を区別する。相手との関係が変わる場面を、文体の不統一として機械的に揃えない。

会話の反復は、同じ語句でも話者や対象が変わり得る。引用範囲を拾えても、話者の同定や皮肉の意味までは形態素解析だけで決まらない。比喩も語の出現数で有用性を決めず、何をどう対応させた表現かを読む。

これらは今後の検出設計の手がかりであり、この手引きの追加によってCLIに新しい検出器が入るわけではない。`repeated_syntax_template`、`antithesis_repetition`、`double_negative`などの既存の指摘が出ても、修正の要否は表の基準で判断する。指摘が出ないことも、表現の良さを保証しない。

この10本だけを根拠に、反復の多さや自分への批判を「人間らしさ」の加点項目にしない。語り手の迷いや不都合な事実を残すことと、自然に見せるためにそれを作ることは別である。元の素材にない経験、感情、失敗、数値を足さない。簡潔で迷いのない文章に、無理に葛藤を持ち込まない。
